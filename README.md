# 门店运营监控看板

美团外卖 + 饿了么数据可视化与异常预警工具。

## 功能

- 📈 **综合概览**：每日营业收入、订单量、转化率趋势
- 🏪 **门店分析**：各门店营业额/订单量排名与明细
- 👥 **流量分析**：按平台拆分的曝光→进店→下单漏斗、新老客占比
- ⚠️ **预警监控**：基于历史均值的 Z-score + 环比下跌异常检测
- 📋 **日报**：选定日期一键生成日报并导出 Excel

## 使用

1. 从美团/饿了么商家后台导出门店数据
2. 在左侧上传文件
3. 自动生成看板

## 本地运行

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```
